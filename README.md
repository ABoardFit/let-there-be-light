# 빛이 있으라

노을과 구름 사이에 떠 있는 작은 섬을 가꾸는 브라우저 정원 게임 데모입니다. Babylon.js로 그린 섬에 소나무와 들꽃, 등불을 놓아 첫 번째 정원을 완성해 보세요. 설치나 로그인 없이 브라우저에서 플레이합니다.

플레이: https://aboardfit.github.io/let-there-be-light/

## 실행

Node.js 22.12 이상을 사용합니다.

```sh
npm install
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

## 놀이 방법

- 아래 도구를 선택하고 빈 타일을 클릭하거나 터치합니다.
- 소나무는 빛 8개, 들꽃은 5개, 등불은 12개를 사용합니다.
- 빛 모으기 버튼이나 중앙의 빛의 샘을 누르면 빛 6개를 얻습니다. 4.5초마다 다시 모을 수 있습니다.
- 게임이 보이는 동안 6초마다 빛 1개가 저절로 모입니다.
- 직접 심은 소나무 5그루, 들꽃 6곳, 등불 4개를 놓으면 정원이 깨어납니다. 이후에도 계속 꾸밀 수 있습니다.
- 비우기는 직접 배치한 장식을 치우고 비용의 절반을 돌려줍니다. 시작할 때 있던 나무, 바위, 샘은 보존됩니다.
- 숫자 1~4로 도구를 고릅니다. 캔버스에 초점을 맞춘 뒤 방향키로 칸을 이동하고 Enter 또는 Space로 배치할 수 있습니다.
- 효과음은 오른쪽 위 버튼으로 켭니다.

## 저장

정원은 현재 브라우저의 `localStorage`에 자동 저장됩니다. 같은 브라우저와 같은 사이트 주소에서 다시 열면 이어서 가꿀 수 있습니다. 다른 기기나 브라우저로 동기화되지 않으며, 사이트 데이터를 지우면 정원도 사라집니다. 저장소가 차단된 환경에서는 저장되지 않으며 화면에 안내가 표시됩니다.

## 그래픽

이끼와 바위 표면, 노을 구름에는 `public/textures/`의 생성 이미지 텍스처를 사용합니다. 섬과 타일의 입체 형태, 풀은 코드로 구성하고, 소나무는 투명 배경 이미지 스프라이트를 고정 카메라에 맞춰 배치한 2.5D 방식입니다. 생성 방식과 프롬프트는 [텍스처 기록](public/textures/ASSETS.md)에 있습니다.

이미지 에셋의 전체 크기는 약 12.3MB입니다. 첫 실행 시 브라우저가 에셋을 내려받으므로 네트워크 속도에 따라 로딩 시간이 달라질 수 있습니다.

## 배포

Vite의 상대 경로 빌드이므로 GitHub Pages 하위 경로에 배포할 수 있습니다. `dist/`에 정적 파일만 만들어지며 서버, 계정, API 키가 필요하지 않습니다. GitHub Actions가 테스트와 빌드를 실행한 뒤 Pages에 배포합니다.

## 구성

- `src/game.js`: 배치, 자원, 목표, 저장 데이터 검증 규칙
- `src/main.js`: 한국어 HUD, 입력, 브라우저 저장, 효과음
- `src/scene.js`: 3D 공중섬과 조명
- `src/style.css`: 데스크톱 및 모바일 화면
- `public/textures/`: 생성 이미지 기반 이끼·바위 텍스처와 소나무 스프라이트
- `tests/game.test.js`: 게임 규칙 검증

Google Fonts의 Noto Serif KR을 불러올 수 없으면 시스템 명조 글꼴로 표시합니다. 모바일 성능은 기기의 그래픽 성능에 따라 달라집니다.
