# 빛이 있으라

노을 속 공중섬에서 펼쳐지는 **5 × 5 전술 카드 전투 데모**입니다. 손패에서 카드를 고른 뒤 전장의 칸을 지정하면 수호자가 이동하거나 해당 범위로 공격합니다. 적의 다음 행동을 읽고 공격, 이동, 방어를 조합해 모든 그림자를 물리치세요.

플레이: https://aboardfit.github.io/let-there-be-light/

## 실행

Node.js 22.12 이상을 사용합니다.

```sh
npm install
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

## 전투 방법

1. 아래 손패에서 카드를 선택합니다. 왼쪽 위 숫자는 필요한 에너지입니다.
2. 빛나는 타일에 커서를 올려 실제 영향 범위를 확인한 뒤 클릭합니다. 이동 카드는 목적지, 방어 카드는 수호자가 서 있는 칸을 선택합니다.
3. 적 머리 위의 행동 표시와 붉은 공격 범위를 확인합니다. 턴 종료를 누르면 적이 행동하고 다음 턴에 에너지와 손패가 갱신됩니다.

첫 손패는 **빛의 찌르기**, **새벽의 횡베기**, **낙광**, **빛의 발걸음**, **수호의 문장**입니다. 카드 안의 작은 격자는 공격이나 이동 범위의 모양을 나타냅니다. 실제 사용 가능 여부와 범위는 전장의 미리보기를 확인하세요.

- 숫자 **1–5**: 해당 손패 선택
- **방향키**: 전장 칸 선택
- **Enter / Space**: 선택한 카드 사용
- **Escape / 오른쪽 클릭**: 카드 선택 취소
- **E**: 턴 종료

키보드 숫자로 카드를 고르면 전장에 초점이 이동합니다. 모바일에서는 손패를 가로로 밀어 카드를 살펴보고 타일을 터치합니다.

## 저장

전투는 현재 브라우저저장소인 `localStorage`에 자동 저장됩니다. 같은 브라우저와 같은 사이트 주소에서 다시 열면 이어서 플레이할 수 있습니다. 기기 간 동기화는 없으며 사이트 데이터를 삭제하면 저장한 전투도 사라집니다. 저장할 수 없는 환경에서는 안내가 표시됩니다.

전투 저장 키는 이전 정원 데모와 분리되어 있어 이전 정원의 저장 데이터는 덮어쓰지 않습니다.

## 그래픽과 배포

전장의 각 칸은 두께가 있는 독립 흙 블럭입니다. 윗면은 모서리 4개·변 4개·중앙의 9슬라이스로 나누며, 블럭 크기를 바꿔도 모서리 폭과 원본 UV 범위를 유지하고 중앙만 늘립니다. 외부 장식 프레임 없이 블럭 자체의 모따기와 흙 단면으로 경계를 표현합니다.

Babylon.js의 고정 시점 3D 전장에 손그림풍 풀밭·흙 텍스처와 2.5D 캐릭터를 배치합니다. 이미지 에셋은 `public/textures/`에 있으며 현재 지형 이미지의 생성 기록은 [STYLIZED-ASSETS-V6.md](public/textures/STYLIZED-ASSETS-V6.md)에 있습니다. 카드 범위 미리보기와 이동·공격 효과는 타일 곡면을 따라 실시간으로 그립니다. 모바일 성능은 기기의 그래픽 성능에 따라 달라집니다.

Vite의 상대 경로 빌드이므로 GitHub Pages 하위 경로에 배포할 수 있습니다. `dist/`에 정적 파일만 만들어지며 서버, 로그인, API 키가 필요하지 않습니다. GitHub Actions가 테스트와 빌드를 실행한 뒤 Pages에 배포합니다. 글꼴을 내려받을 수 없으면 시스템 명조 글꼴을 사용합니다.

## 구성

- `src/game.js`: 카드, 전장, 턴, 적 행동, 저장 데이터 검증 규칙
- `src/main.js`: 한국어 전투 HUD, 입력, 저장
- `src/scene.js`: 3D 전장, 캐릭터, 타일 범위와 전투 효과
- `src/style.css`: 데스크톱 및 모바일 손패 화면
- `public/textures/`: 생성 이미지 기반 그래픽 에셋
- `tests/game.test.js`: 전투 규칙 검증
